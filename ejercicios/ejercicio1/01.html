¿Qué es HTML?

HTML es un lenguaje de marcado que se utiliza para estructurar el contenido de las páginas web.

A través de etiquetas, permite organizar títulos, párrafos, imágenes y otros elementos para que el navegador pueda interpretarlos correctamente.

HTML se enfoca en la estructura de la información, mientras que el diseño visual se trabaja con otros lenguajes como CSS.
